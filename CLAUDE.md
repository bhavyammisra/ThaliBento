# ThaliBento (Bhavyam's copy)
Special-meal safety net for Japan Airlines that plugs into JAL's existing tools: diet form → rules → JAL meal code + kitchen note, lost-meal alerts from passenger lists, a late-change ladder, and an offline crew copilot. Built by team Caffeinated Nerds (Bhavyam Misra, Gunagye Jain, Shefali Sharma) for the Thapar Japan Hackathon 2026. Copied from GunagyeJain/thapar-japan-hackathon-code with full history.
